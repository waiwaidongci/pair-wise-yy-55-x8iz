# 音乐总谱编辑、移调与分谱出版准备平台

源提示词编号：12。支持多声部总谱、VexFlow 五线谱、音符与力度/连音/表情编辑、移调乐器、分谱提取与换页提示音、版本差异、评论锚点、撤销重做、打印和未保存恢复。

## 离线排练协作

指挥、作曲、出版三个角色在排练场断网时各自修改总谱与分谱，网络恢复后通过「同步与冲突中心」（`/merge`）导出/导入 JSON 草稿包进行三方合并。

- **草稿包三方合并**：以 `baseVersionId` 对应的共同基线合并；单边修改自动采纳，同一音符两边都改过时按**角色优先级（作曲 > 指挥 > 出版）再按更新时间**保留一个可出版值，另一版的完整音符值进入冲突记录，可在冲突表中一键「改用另一版」，改动不会悄悄消失。删除冲突（一方改、一方删）同样按角色裁决并记录删除意图。
- **移调联动重算**：声部移调后立即重算分谱页数（升降号密度影响每页容量）、换页前提示音小节数与换页建议；换页建议锚定具体音符而非小节序号。
- **稳定锚点与跟随**：每个音符带 `measure/beat` 稳定锚点；评论锚定声部 + 音符，音符增删/改时值导致位置移动后，评论与换页建议自动跟随到新小节。旧草稿（无锚点字段）导入时按声部和小节补回锚点。
- **失败可重试**：损坏草稿包合并失败时原包原文与失败原因被保留（含 localStorage 持久化），当前总谱不动，可用原包重试或复制排查。
- **重开续草稿**：完整草稿（总谱、评论、换页、冲突记录、失败包、合并流水）持久化到 localStorage，重开页面后从完整草稿继续；「形成版本」后清除草稿。

## 目录

- `src/collab/pitch.ts`：移调、分谱页数/提示音/换页建议计算
- `src/collab/anchor.ts`：小节拍位锚点、评论/换页跟随、旧草稿锚点补齐
- `src/collab/merge.ts`：三方合并、角色+时间裁决、冲突记录、草稿包校验

## 技术栈

React、Ant Design、Redux Toolkit、React Router、RTK Query、VexFlow、Vite、TypeScript。

## 运行

```bash
npm install
npm run dev
```

开发地址：http://localhost:62055

```bash
npm run build
npm test   # 合并引擎与 store 恢复流程测试（esbuild 打包后用 node 运行，无需额外依赖）
```

`/merge` 页面提供两个演练按钮：模拟对方断网草稿（圆号力度两边同改 → 冲突；长笛表情单边改 → 自动采纳）与模拟损坏草稿包（验证失败保留与重试）。
